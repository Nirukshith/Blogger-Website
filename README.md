# 🖋️ Truman Writes

**Truman Writes** is a dynamic full-stack blog platform where creativity meets community.  
It’s built to empower writers to express their ideas freely and readers to explore diverse perspectives — all in one place.

---

## 🌐 Live Website
🔗 [trumanwrites.lovestoblog.com](http://trumanwrites.lovestoblog.com)

---

## 🚀 Features

- ✍️ **Create & Publish Posts:** Users can write and share their blogs instantly.  
- 👤 **User Authentication:** Secure registration and login system.  
- 📰 **Explore Posts:** View blogs from other users across different topics.  
- 🏷️ **Categorization:** Posts organized by topics for easy navigation.  
- 💬 **Community Interaction:** Comment and engage with others’ posts.  
- ⚙️ **Admin Panel:** Manage posts, topics, and users efficiently.  
- 📱 **Responsive Design:** Optimized for both desktop and mobile devices.
